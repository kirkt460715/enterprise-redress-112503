# 涉企诉求办结与再转办的责任时钟分析

企业议题、部门回执、反馈承诺和责任边界。资料中的企业、机构、事件和观测全部为合成资料。

## 交换格式

`input/` 是同一经营流程各来源的资料包。每个 JSONL 文件一行一个对象，编码为 UTF-8。日期为当地自然日，带时区的时间戳使用 UTC+08:00。没有值的字段用 `null`，对象身份以各表说明的主键为准。输入文件的排列顺序不代表业务发生顺序。

- `organizations.jsonl` 记录参与转办的窗口与部门。
- `cases.jsonl` 记录各政企渠道提交的企业议题。
- `identity.jsonl` 记录企业对来件是否属于同次事项的确认。
- `events.jsonl` 记录主协办回执、补件、企业通知与复开。
- `promise.jsonl` 记录窗口向企业确认过的对象与时限。
- `targets.jsonl` 记录事项类别的目标处理时限。
- `contact.jsonl` 记录协调会可用于联系承办单位的实际窗口。
- `classifications.jsonl` 记录各片区过渡期间可用的类别范围及比较用父类。
- `meetings.jsonl` 记录已使用的周度资料范围与口径备注。

字段、单位和来源约定见 [资料字典](资料字典.md)。

## 本地读取与核对

使用 Python 3.11.2，无需安装第三方包。以下命令从项目根目录运行。

```sh
python3 -m source_bundle input
python3 -m unittest discover -s tests
```

第一条命令检查交付格式并输出来源表行数，第二条命令核对样本和格式异常。其他资料包可替换为同格式的目录。
